> 版本：1.0 | 日期：2026-05-16 | 作者：ershiqijian

## 1. 项目概述

**SmartPai** 是一个基于 RAG（检索增强生成）的企业级知识问答系统，支持文档上传、向量检索、多智能体协作和实时流式对话。

**核心能力：**
- 文档解析与向量化存储
- 混合检索（关键词 + 语义向量）
- 多智能体编排（意图识别 → 任务执行 → 质量校验）
- 实时 WebSocket 流式输出
- 多租户（组织标签）隔离

## 4. 模块说明

### 4.1 MCP 引擎（核心编排）

路径：`mcp/core/McpEngine.java`

7阶段流水线：

```
请求 → PreRouter路由 → 技能选择 → 上下文构建 → LLM调用 → 质量校验 → 记忆存储 → 响应输出
```

**子模块：**

| 子模块 | 路径 | 说明 |
|--------|------|------|
| 技能插件 | `mcp/skill/impl/` | RagSkill、SearchSkill、QaSkill、SummarySkill、CheckSkill、WebSearchSkill |
| 前置路由 | `mcp/router/impl/` | DateTimeRouter（时间路由）、WebSearchRouter（网络搜索路由） |
| 上下文 | `mcp/context/McpContext.java` | 请求状态与上下文数据 |
| 记忆管理 | `mcp/memory/MemoryManager.java` | Q&A 记忆持久化 |
| 函数注册 | `mcp/function/FunctionRegistry.java` | 技能动态注册 |

### 4.2 RAG 服务

| 类 | 说明 |
|----|------|
| `LangChain4jRagService.java` | 核心 RAG 流程：向量检索 + LLM 生成 |
| `HybridSearchService.java` | 混合检索：BM25关键词 + 向量语义 |
| `ElasticsearchService.java` | ES 文档 CRUD、向量索引操作 |
| `VectorizationService.java` | 文本 → 向量（text-embedding-v4） |
| `LangGraphRagService.java` | 基于状态机的 RAG 流程（LangGraph实现） |

### 4.3 多智能体（Multi-Agent）

路径：`service/agent/`

```
用户请求
    │
    ▼
AgentOrchestrator（编排器）
    ├── IntentAgent（意图识别）
    ├── WorkAgent（任务执行）
    └── CheckAgent（质量校验）
```

WebSocket 入口：`MultiAgentWebSocketHandler.java`

### 4.4 文档处理流水线

```
文件上传（UploadController）
    │
    ▼
MinIO 存储（原始文件）
    │
    ▼
Kafka 消息（file-processing-topic1）
    │
    ▼
FileProcessingConsumer（异步消费）
    │
    ├── Apache Tika 解析（ParseService）
    ├── 文本分块（ChunkInfo）
    └── 向量化 + ES 存储（VectorizationService）
```

### 4.5 认证与授权

| 组件 | 说明 |
|------|------|
| `JwtAuthenticationFilter` | 每次请求验证 JWT Token |
| `OrgTagAuthorizationFilter` | 基于组织标签的数据隔离 |
| `SecurityConfig` | 白名单路径、CORS 配置 |
| `JwtUtils` | Token 生成与解析 |

Token 存储：Redis（支持失效控制）

### 4.6 WebSocket 处理器

| Handler | 路径 | 用途 |
|---------|------|------|
| `ChatWebSocketHandler` | `/ws/chat` | 普通对话流式输出 |
| `McpWebSocketHandler` | `/ws/mcp` | MCP 引擎事件流 |
| `MultiAgentWebSocketHandler` | `/ws/agent` | 多智能体协作流 |

## 6. 数据模型

### 6.1 数据库表（MySQL）

| 实体 | 表 | 说明 |
|------|----|------|
| `User` | users | 用户账号，含角色和组织标签 |
| `Conversation` | conversations | 对话会话 |
| `FileUpload` | file_uploads | 上传文件元数据 |
| `DocumentVector` | document_vectors | 向量文档记录 |
| `ChunkInfo` | chunk_infos | 文档分块信息 |
| `FileProcessingTask` | file_processing_tasks | 异步任务状态 |
| `OrganizationTag` | organization_tags | 组织/租户标签 |

### 6.2 Elasticsearch 索引

- 向量维度：**2048**（text-embedding-v4）
- 索引映射配置：`resources/es-mappings/`
- 支持 kNN 向量检索 + BM25 全文检索

### 6.3 Redis 数据

| Key 类型 | 用途 |
|----------|------|
| JWT Token | 登录态管理 |
| Q&A 记忆 | 相似问题缓存（QaMemoryService） |
| 组织标签缓存 | OrgTagCacheService |

## 7. 配置说明

配置文件：`src/main/resources/application.yml`

```yaml
server:
  port: 8081

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/PaiSmart
    username: root
    password: 123456

  data:
    redis:
      host: localhost
      port: 6379

  kafka:
    bootstrap-servers: localhost:9092

  servlet:
    multipart:
      max-file-size: 50MB
      max-request-size: 100MB

minio:
  endpoint: http://localhost:9000
  access-key: minio
  secret-key: minio123456
  bucket: uploads

elasticsearch:
  host: localhost
  port: 9200

ai:
  chat-model: qwen-turbo
  embedding-model: text-embedding-v4
  base-url: https://dashscope.aliyuncs.com/compatible-mode/v1
  embedding-dimensions: 2048
```

**初始管理员账号：**
- 用户名：`admin`
- 密码：`admin1234`
- 组织：`default`
